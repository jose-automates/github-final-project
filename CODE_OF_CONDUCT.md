# Code of Conduct

## Our Pledge

We are committed to providing a respectful, welcoming, and inclusive environment for everyone contributing to this project.

## Expected Behavior

- Be respectful and considerate.
- Communicate constructively and professionally.
- Welcome feedback and different perspectives.
- Focus on collaboration and learning.

## Unacceptable Behavior

Harassment, discrimination, offensive language, and disrespectful conduct will not be tolerated.

## Enforcement

Project maintainers may remove contributions or restrict participation when these standards are violated.

## Scope

This Code of Conduct applies to all project interactions, including issues, pull requests, and discussions.
